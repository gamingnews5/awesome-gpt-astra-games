## Source description

A cute protistology game for the browser, and the sister game to PetriPals, FunGals and CellMates. Protists are the single cells (and a few bigger ones) that aren't bacteria, fungi, plants or animals: amoebas, ciliates, flagellates, algae, slime molds and… Commit carries an exact Claude Opus 5.5 co-author trailer.
