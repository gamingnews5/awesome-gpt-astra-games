## Source description

An iPhone word game where you rebuild Bible verses (KJV) from a letter wheel, level by level, until you can say them from memory. A painting lights up behind each story as you play. Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
