## Source description

A noir detective game that runs in the browser. You open the office door, walk into a dark room, and find pages pinned to the wall. Every page hides exactly one mistake. Find it, accuse the line, and the page gets stamped CLEARED. Commit carries an exact Claude Opus 5.5 co-author trailer. Live demo returned HTTP 200 (availability only, not a playtest).
