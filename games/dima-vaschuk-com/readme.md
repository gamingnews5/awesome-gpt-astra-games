## Source description

Dima's capybara game: Capybara Rush, an endless runner in a single public/index.html (canvas + WebAudio, no dependencies). Collect oranges that stack on the capybara's head as a shield; jump logs/rocks/croc ponds, duck bees, grab power-ups. Commit carries an exact Claude Opus 5.5 co-author trailer.
