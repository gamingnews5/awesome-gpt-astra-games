## Source description

A space-themed 2D platformer for the browser, built with Phaser 3. All art is original pixel art defined in code, and every sound effect is synthesized with WebAudio, so there are no asset files. Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
