## Source description

A party word game in the style of Scattergories. Choose six categories, draw a letter, and everyone writes an answer beginning with that letter for each category. Scores are kept on paper. Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
